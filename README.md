# CML Networking Home Lab

A virtual home lab built in Cisco CML Free (5-node limit) to practice core networking skills. Each folder is a self-contained lab with its topology, configs, verification, and notes.

## Labs
| Lab | Skill | Status |
|---|---|---|
| 01 | VLANs, trunking, inter-VLAN routing | Complete |
| 02 | DHCP and static addressing | In progress |
| 03 | OSPF | Planned |
| 04 | NAT/PAT | Planned |
| 05 | ACLs | Planned |
| 06 | Security hardening | Planned |
| 07 | STP | Planned |
| 08 | Ops basics | Planned |

## Tools
Cisco CML Free, IOSv, IOSvL2, Ubuntu
